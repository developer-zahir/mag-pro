Mag Pro is an ultra-fast, modern, lightweight, and fully responsive magazine and blog WordPress theme with built-in Elementor Header & Footer Builder, Dark & Light Mode, and advanced post widgets.

== Description ==

Mag Pro is built completely from scratch by Developer Zahir (https://developerzahir.com/). It provides an ultra-lightweight codebase, blazing fast load times, and complete design freedom with Elementor Header & Footer Builder.

Features:
- Elementor Header & Footer Builder with target display conditions
- Instant Dark & Light Mode with zero flash
- 12 Elementor magazine and blog widgets via Mag Pro Elements
- Post view counter built-in
- Clean semantic HTML5 markup
- Fully responsive across mobile, tablet, and desktop
